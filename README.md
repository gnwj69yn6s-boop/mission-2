나만의 프롬프트 관리 프로그램
📌 프로젝트 소개

나만의 프롬프트 관리 프로그램은 Python을 활용하여 제작한 콘솔 기반 프롬프트 관리 프로그램입니다.

생성형 AI를 사용하면서 자주 사용하는 프롬프트가 많아지면 원하는 프롬프트를 찾기 어려워지는 문제를 해결하기 위해 제작했습니다.

사용자는 프로그램을 통해 프롬프트를 직접 추가하고, 저장된 프롬프트를 목록으로 확인할 수 있습니다. 또한 카테고리별로 프롬프트를 조회하거나 키워드를 이용하여 원하는 프롬프트를 검색할 수 있습니다.

자주 사용하는 프롬프트는 즐겨찾기에 추가하여 별도로 관리할 수도 있습니다.

이 프로젝트를 제작하면서 Python의 기본 문법뿐만 아니라 리스트, 딕셔너리, 조건문, 반복문, 함수 등을 실제 프로그램에 적용하는 방법을 학습했습니다. 또한 Git과 GitHub를 사용하여 프로젝트의 변경 이력을 관리하고 코드를 저장소에 업로드하는 방법을 익혔습니다.

🚀 실행 방법
1. Python 설치 확인

터미널에서 다음 명령어를 입력합니다.

python --version


Python 3.10 이상의 버전이 설치되어 있어야 합니다.

Windows 환경에서 python 명령어가 동작하지 않는 경우 다음 명령어를 사용할 수 있습니다.

py --version

2. 프로젝트 다운로드

GitHub 저장소를 clone하여 프로젝트를 다운로드할 수 있습니다.

git clone 저장소_URL


프로젝트 폴더로 이동합니다.

cd prompt-manager

3. 프로그램 실행

다음 명령어를 입력하여 프로그램을 실행합니다.

python prompt_manager.py


Windows에서 python 명령어가 동작하지 않는 경우:

py prompt_manager.py

✨ 주요 기능
1. 프롬프트 추가

새로운 프롬프트를 프로그램에 등록할 수 있습니다.

프롬프트를 추가할 때 다음 정보를 입력합니다.

제목

내용

카테고리

제목이나 내용이 비어 있는 경우 다시 입력하도록 처리했습니다.

추가된 프롬프트의 즐겨찾기 기본값은 False로 설정됩니다.

예시:

=== 프롬프트 추가 ===

제목: 블로그 글 작성 도우미
내용: SEO에 최적화된 블로그 글을 작성해주세요.

카테고리 선택:
1) 텍스트 생성
2) 이미지 생성
3) 영상 생성
4) 페르소나
5) 자동화
6) 기타

선택: 1

프롬프트가 추가되었습니다!

2. 프롬프트 목록

현재 프로그램에 등록되어 있는 모든 프롬프트를 확인할 수 있습니다.

각 프롬프트는 다음과 같이 표시됩니다.

번호

카테고리

제목

즐겨찾기 여부

즐겨찾기로 등록된 프롬프트에는 ⭐ 표시가 나타납니다.

예시:

=== 프롬프트 목록 ===

1. [텍스트 생성] 블로그 글 작성 도우미 ⭐
2. [이미지 생성] 제품 썸네일 생성
3. [페르소나] IT 컨설턴트 페르소나

총 3개의 프롬프트

3. 카테고리별 조회

원하는 카테고리를 선택하면 해당 카테고리에 등록된 프롬프트만 확인할 수 있습니다.

카테고리를 선택하면 해당 카테고리의 프롬프트 목록과 총 개수를 출력합니다.

해당 카테고리에 등록된 프롬프트가 없는 경우 안내 메시지를 출력합니다.

4. 프롬프트 검색

키워드를 입력하여 프롬프트를 검색할 수 있습니다.

검색은 프롬프트의 제목과 내용을 대상으로 수행합니다.

예를 들어 블로그라는 검색어를 입력하면 제목이나 내용에 블로그가 포함된 프롬프트가 검색됩니다.

예시:

=== 프롬프트 검색 ===

검색어: 블로그

검색 결과:

1. [텍스트 생성] 블로그 글 작성 도우미 ⭐

1개의 프롬프트를 찾았습니다.


검색 결과가 없는 경우에는 검색 결과가 없다는 안내 메시지를 출력합니다.

5. 프롬프트 상세 보기

프롬프트 번호를 입력하면 해당 프롬프트의 전체 내용을 확인할 수 있습니다.

상세 보기에서는 다음 정보를 확인할 수 있습니다.

제목

카테고리

즐겨찾기 여부

프롬프트 전체 내용

예시:

=== 프롬프트 상세 보기 ===

번호 입력: 1

----------------------------------------
제목: 블로그 글 작성 도우미
카테고리: 텍스트 생성
즐겨찾기: ⭐
----------------------------------------
내용:
당신은 전문 블로거입니다.
주어진 주제에 대해 SEO에 최적화된
블로그 글을 작성해주세요.
----------------------------------------


잘못된 번호를 입력하면 올바른 번호를 입력하도록 안내합니다.

6. 즐겨찾기 관리

프롬프트 번호를 입력하여 해당 프롬프트를 즐겨찾기에 추가하거나 해제할 수 있습니다.

현재 즐겨찾기가 해제되어 있다면 즐겨찾기로 변경되고, 이미 즐겨찾기로 등록되어 있다면 즐겨찾기가 해제됩니다.

예시:

=== 즐겨찾기 관리 ===

번호 입력: 2

'제품 썸네일 생성' 프롬프트를
즐겨찾기에 추가했습니다!

7. 즐겨찾기 목록

즐겨찾기로 등록된 프롬프트만 모아서 확인할 수 있습니다.

즐겨찾기가 등록된 프롬프트가 없다면 안내 메시지를 출력합니다.

예시:

=== 즐겨찾기 목록 ===

1. [텍스트 생성] 블로그 글 작성 도우미 ⭐
2. [이미지 생성] 제품 썸네일 생성 ⭐

총 2개의 즐겨찾기

예시:

블로그 글 작성

이메일 작성

보고서 작성

SNS 게시글 작성

2. 이미지 생성

AI 이미지 생성에 사용할 수 있는 프롬프트를 관리합니다.

예시:

제품 이미지

썸네일 이미지

광고 이미지

일러스트 이미지

3. 영상 생성

영상 제작 및 영상 콘텐츠에 사용할 수 있는 프롬프트를 관리합니다.

예시:

광고 영상

쇼츠 영상

영상 시나리오

영상 장면 구성

예시:

IT 컨설턴트

마케팅 전문가

전문 블로거

영어 회화 선생님

반복적인 작업을 자동화하거나 업무 프로세스를 구성하기 위한 프롬프트를 관리합니다.

예시:

뉴스 요약

데이터 정리

반복 업무 자동화

콘텐츠 제작 자동화

6. 기타

위의 카테고리에 해당하지 않는 다양한 프롬프트를 관리합니다.

💾 데이터 구조

프롬프트 데이터는 Python의 **리스트(List)와 딕셔너리(Dictionary)**를 사용하여 관리합니다.

기본적인 데이터 구조는 다음과 같습니다.

prompts = [
    {
        "title": "블로그 글 작성 도우미",
        "content": "SEO에 최적화된 블로그 글을 작성해주세요.",
        "category": "텍스트 생성",
        "favorite": True
    }
]


각 프롬프트는 딕셔너리로 구성되어 있으며, 여러 개의 프롬프트는 리스트에 저장됩니다.

각 프롬프트에는 다음과 같은 데이터가 포함됩니다.

항목	설명
title	프롬프트 제목
content	프롬프트 내용
category	프롬프트 카테고리
favorite	즐겨찾기 여부
📌 기본 데이터

프로그램을 처음 실행하면 이전 미션에서 작성한 프롬프트를 기반으로 최소 3개의 기본 프롬프트가 등록되어 있습니다.

기본 데이터 예시:

블로그 글 작성 도우미

제품 썸네일 생성

IT 컨설턴트 페르소나

프로그램 실행 중에는 새로운 프롬프트를 추가하거나 즐겨찾기 상태를 변경할 수 있습니다.

🔄 데이터 저장 방식

현재 버전에서는 별도의 데이터베이스나 JSON 파일을 사용하지 않습니다.

프로그램 실행 중에 생성하거나 변경한 데이터는 Python의 리스트에 저장됩니다.

따라서 프로그램을 종료하면 실행 중 추가한 프롬프트와 즐겨찾기 변경 사항은 초기화됩니다.

프로그램을 다시 실행하면 처음 설정된 기본 프롬프트 데이터가 다시 등록됩니다.

🧩 코드 구성

프로그램의 모든 기능을 하나의 함수에 작성하지 않고 기능별로 함수를 분리하여 구현했습니다.

주요 함수는 다음과 같습니다.

show_menu()
메인 메뉴 출력

add_prompt()
새로운 프롬프트 추가

show_list()
전체 프롬프트 목록 출력

show_by_category()
카테고리별 프롬프트 조회

search_prompt()
프롬프트 검색

show_detail()
프롬프트 상세 보기

manage_favorite()
즐겨찾기 추가 및 해제

show_favorites()
즐겨찾기 목록 출력


기능을 함수별로 분리함으로써 코드의 가독성과 유지보수성을 높였습니다.

Git을 활용하여 기능별 변경 내용을 기록하고 프로젝트의 버전을 관리했습니다.
