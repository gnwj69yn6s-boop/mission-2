나만의 프롬프트 관리 프로그램

Python으로 만든 콘솔 기반 프롬프트 관리 프로그램입니다.

자주 사용하는 프롬프트를 카테고리별로 관리하고, 검색 및 즐겨찾기 기능을 통해 원하는 프롬프트를 쉽게 찾을 수 있습니다.

개발 환경

Python 3.10 이상

VSCode

Git

GitHub

실행 방법

프로젝트 폴더에서 터미널을 열고 다음 명령어를 실행합니다.

python prompt_manager.py


Windows에서 python 명령어가 실행되지 않는 경우:

py prompt_manager.py

데이터 구조

프롬프트 데이터는 Python의 리스트와 딕셔너리를 사용하여 관리합니다.

각 프롬프트는 다음 정보를 포함합니다.

제목

내용

카테고리

즐겨찾기 여부

데이터 저장 방식

현재 프로그램은 실행 중에만 프롬프트 데이터를 유지합니다.

프로그램을 종료하면 추가하거나 변경한 데이터는 초기화되며, 프로그램을 다시 실행하면 기본 프롬프트 데이터가 다시 등록됩니다.

프로젝트 목표

이 프로젝트를 통해 Python의 변수, 조건문, 반복문, 함수, 리스트, 딕셔너리 등의 기초 문법을 실제 프로그램에 적용하고, Git과 GitHub를 활용하여 프로젝트의 버전을 관리하는 방법을 학습했습니다.
