# 나만의 프롬프트 관리 프로그램

Python으로 제작한 콘솔 기반 프롬프트 관리 프로그램입니다.
프롬프트를 추가하고, 목록을 확인하고, 검색하거나 즐겨찾기로 관리할 수 있습니다.

## 실행 방법

1. Python 3.10 이상이 설치되어 있어야 합니다.
2. 프로젝트 폴더에서 터미널을 실행합니다.
3. 아래 명령어를 입력합니다.

python prompt_manager.py

## 주요 기능

- 프롬프트 추가
- 프롬프트 목록 보기
- 카테고리별 조회
- 프롬프트 검색
- 프롬프트 상세 보기
- 즐겨찾기 추가 및 해제
- 즐겨찾기 목록 보기
- 프로그램 종료

## 프롬프트 카테고리

- 텍스트 생성
- 이미지 생성
- 영상 생성
- 페르소나
- 자동화
- 기타
